A DTE manager enables Chilean POS returns in the company settings after closing
all active POS sessions. New sessions freeze the policy. Keep the existing company
accounting-mode selector; each return preserves its original sale's mode even if
the receiving session uses another mode.

Cashiers need Internal User, POS User and DTE User permissions. Configure manual
cash or bank payment methods and the receiving store's native stock picking type.
A current CAF61 and signing profile are required by the existing DTE services.
No additional accounting ACL or raw fiscal-evidence access is granted to cashiers.

The addon currently requires Chile, CLP, 19% VAT or exempt original details and
Demo evidence. Enabling this option does not change a company's SII environment.
