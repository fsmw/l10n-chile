Import an original SII certification set from the DTE Operations menu, under
Certification Sets and Import Original SET. The source is stored as evidence.
DTE managers can analyze numbered sections, ordered cases, document types, and
source lines. Unrecognized structure is reported as a block; analysis never
changes the original file or creates accounting documents. Re-importing the
same bytes for the same company is rejected. No source data is included in this
addon.
