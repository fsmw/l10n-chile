Preserves the original SII certification set TXT per company, including
its exact bytes, filename, size and SHA-256 digest. Imported source
records are immutable and can only be created through the import wizard.

Usage
=====

Import an original SII certification set from the DTE Operations menu,
under Certification Sets and Import Original SET. The source is stored
as evidence. DTE managers can analyze numbered sections, ordered cases,
document types, and source lines, then create immutable case snapshots
that preserve the exact instructions, source digest, and line ranges.
Unrecognized document types stay visible as unsupported cases. This does
not create accounting documents or consume folios. Re-importing the same
bytes for the same company is rejected. No source data is included in
this addon.

DTE managers can interpret case snapshots after reviewing them. This
versioned pass extracts only explicit detail columns, note references
and correction markers. It keeps source-line provenance for extracted
values and reports unrecognized or incomplete instructions for review.
It does not create accounting documents, resolve business partners or
products, reserve folios, or send information to the SII.

The case coverage summary separates interpreted cases from those needing
review, unsupported document types, and cases not yet interpreted. The
coverage check reports these counts and stays in warning state until
every case has been reviewed successfully.

Recognized detail rows are materialized as ordered, immutable case-line
snapshots. Each row retains its explicit values, source line, source
digest, and interpreter version for later operator mapping.
