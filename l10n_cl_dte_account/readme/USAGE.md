Set the company SII mode to Demo from Settings > Companies, then select
**Prepare Demo Configuration** beside the mode selector. Choose one or more
Chilean DTE types in the tag field. The confirmation wizard creates a synthetic
Demo trust key, one signed CAF for each selected type, and a disposable company
signing certificate/profile. Type 33 is selected by default. The company must
have a valid Chilean RUT. Existing CAFs and signing profiles are never changed;
the wizard can add missing synthetic CAF types to an existing synthetic Demo
profile.

After setup, post a customer invoice and choose **Issue DTE** in the invoice
header. Types 33 and 34 use this addon's invoice serializer; type 34 requires
exempt-only invoice lines. When `l10n_cl_dte_boleta` is installed, types 39 and
41 use its separate boleta serializer; type 41 requires exempt-only lines. The
selected type determines the CAF, folio, TED, XML and durable submission. The
asynchronous Demo gateway simulates submission and status polling;
its TrackID and evidence are clearly marked `DEMO / SIMULADO`. They are not an
SII receipt. The queue-job runner must be active to process the submission.

If an invoice is reset to draft before a DTE is created, its document type can
be changed. The accounting number is recomputed when it is posted again. Other
CAF types generated by the setup wizard are prepared for future
source-document flows and cannot yet be issued from customer invoices. Boleta
issuance is limited to Demo and standard posted customer invoices in CLP; POS,
periodic services, and Certification/Production transports are outside its
current scope. The annual 135 UF rule is checked against the local UF rate as
of December 31 of the previous year. Above that limit, a named receiver and
payment method are required; an anonymous receiver is rejected.

The generated trust key, CAF private key, and signing certificate are synthetic
local test material. Never use them in Certification or Production. Those modes
remain unavailable until their real SII transport adapters are installed.
