Issue Chilean electronic sales receipts type 39 and exempt/non-taxable receipts type 41 from posted customer invoices. The addon keeps boleta data validation and XML composition separate from the invoice 33/34 serializer while reusing the shared CAF, folio, signing, evidence, and submission lifecycle. It validates signed boletas against the SII's separate `EnvioBOLETA_v11.xsd` schema. The downloaded SII schema has an invalid nested percentage restriction (`0.00` below its base minimum `0.01`); the compatibility copy tightens those two restrictions to `0.01`, which matches the base type and has no effect on emitted XML because zero discounts and surcharges are omitted. The unmodified SII source schema is retained alongside the compatibility schema for provenance.
